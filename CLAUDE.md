# Project: Quite Orbit M LLC Company Website

## Purpose
A company website for Quite Orbit M LLC, a software development company. Built solely to satisfy Apple Developer Program enrollment, which requires a real, working website on the company's own domain (quiteorbit.com). Not a marketing site or product site.

## Key facts
- Company: Quite Orbit M LLC (exact legal name, must match D-U-N-S record on the site)
- Domain: quiteorbit.com
- Company's product: Back Here, an app for managing maladaptive daydreaming (MD)
- This site is intentionally separate from Back Here's branding (dark earthy palette, Literata/Manrope fonts). Do not reuse that design system here.

## Stack
- Static HTML/CSS, no framework, no backend
- Deploys via GitHub → Vercel or Netlify
- Mobile responsive

## Structure
Single page: Header → Hero/one-liner → About paragraph → "What we're building" (Back Here mention) → Contact → Footer

## Constraints
- No placeholder/lorem ipsum text, all copy should be real and final
- No templated/generic look, use deliberate design choices (frontend-design skill)
- Must read as a legitimate, established small company, not a single-app landing page

## Out of scope for this project
- DNS setup and actual deployment (manual, done by the user after review)
- Privacy policy page (not required at this stage, only needed later at app submission)
- Multi-page structure, blog, or any content beyond the single page above
